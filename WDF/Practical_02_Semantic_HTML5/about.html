About SYNORA Portal

Synora is a modern academic student portal designed to bring university schedule notices, course curriculums, campus events, and student services into one coherent, accessible frontend interface.

🎯 Problem Definition & Statement

Students regularly receive critical academic data across fragmented channels: timetable updates on notice boards, laboratory batch allocations on group messages, and event circulars via email.

Synora unifies this campus ecosystem into a single accessible portal while directly demonstrating the practical competencies covered in the ITUE203 laboratory curriculum.

Academic Scope Boundary: Strictly frontend implementation (HTML5, CSS3, JavaScript ES6+, JSON, Fetch API, LocalStorage). Server runtime (PHP/MySQL) is intentionally reserved for subsequent practicals.
